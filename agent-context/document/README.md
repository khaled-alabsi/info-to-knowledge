# knowledge/ - what is TRUE, situationally

The catalogue a worker browses with `list_document()` and opens with `read_document(name)`.

This is the right mechanism only for material whose relevance the worker can judge from a one-line
summary. Anything the phase is simply wrong without belongs in `../base/`, injected.

`index.json` is the catalogue. Ids use dots, never slashes, so they cannot be mistaken for paths.
