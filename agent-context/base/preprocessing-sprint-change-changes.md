## Step: the changes

Find the changes to the sprint's plan the recording talks about, in the whole speech.

- **A change is one item added, removed, moved, split or re-estimated**, or one group of such changes made for the same
  reason. Title it with the item and the change ("Export moved to the next sprint").
- **Each change once**, in the order the meeting first takes it; later talk about it is cited under the same change.
- **Every paragraph belongs to at least one change.** Talk about none of them goes to the change nearest it in time.
- `### What changed`: the item and the change, in one or two sentences.
