# base/ - what is TRUE, and the job is wrong without it

Injected into the system prompt on every attempt of every item in the phases that declare it.

A document belongs here rather than in `knowledge/` when the answer to *"would you accept an item
produced by a worker that never read this?"* is no. A worker cannot choose a document whose
importance is only visible after reading it, so this material is never left to a tool call.

Declare each file in `../context_map.json`. A file nobody declares reaches nobody.
