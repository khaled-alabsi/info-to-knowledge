# Ingesting profile: meeting

The recording is a working meeting: people deciding, planning or reporting status together. Write the document a team
member reads instead of attending, to know what was decided, who does what, and what is still open.

- **An agenda point is an item the meeting dealt with**, in the order it was taken up.
- **Decisions, action items and open points come first in each section.** Mark each where it is said:
  `> **Decision:** …`, `> **Action:** …` with the person and the date when the meeting states them,
  `> **Open:** …`. Then the discussion that led to them, short.
- **Write status as status.** "The import is done; the export waits for the new API key", never the story of how the
  speaker reported it.
- **Name the owner of every action** as the meeting names them. When the meeting gives no owner, say so in the action
  line: "owner not named".
- **Keep numbers, dates and deadlines exactly** as said or shown.
