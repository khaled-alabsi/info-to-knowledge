# Ingesting profile: conversation

The recording is a conversation: two people, or a few, talking with each other as equals (an interview, a chat, a
discussion), with no slides and no agenda. Write the document a reader uses to know what was said and who thinks what,
without listening to it.

- **An agenda point is a topic of the conversation**: where the talk turns to a new subject, in the order it happened.
  A topic the speakers return to later is a later agenda point with the same title.
- **Keep who holds which view.** The notes name the speakers `Speaker A`, `Speaker B` and so on, as phase 2 told them
  apart from the wording. Use those names, or the person's own name where the conversation states it ("I am Jonas").
  Write "Speaker A thinks the release should wait; Speaker B wants it this week", never one merged opinion.
- **Write each exchange as its outcome**, never as a dialogue: the question, the answer, and where they agreed or
  disagreed. A disagreement left open is an `> **Open:**` line.
- **Keep the reasons.** A view without its reason is half the information: "Speaker B wants it this week, because the
  customer is waiting".
- **Nothing is invented to fill a gap.** When the wording does not show who said something, write it without a name,
  never with a guessed one.
