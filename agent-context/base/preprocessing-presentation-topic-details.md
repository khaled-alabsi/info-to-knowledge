## Step: one topic in detail

Write out the one topic this request is about, from its paragraphs and from what the first step wrote about it.

- `### Concepts`: each idea the topic builds, in the order the speaker builds it.
- `### Definitions`: each term the speaker defines, with the definition as given.
- `### Examples`: each example, case or demonstration the speaker gives, and what it shows.
- `### Claims`: each claim the speaker makes, with its support (a number, a source, a reason) when given.
